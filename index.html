case.01 — connected hardware · bachelor's thesis · 2024

Indoor Tracking System

A zone-based retail tracking prototype built as one connected system: an infrared transmitter defines the zone, a cart-mounted receiver detects entry and the software pipeline turns the event into useful information.

Mar–Oct 2024
// one project · two physical nodes

I designed the infrared pipeline, embedded firmware, modular architecture, hardware schematics, prototypes and custom 3D-printed enclosures.

Select the system or either device to inspect how the parts connect and how each prototype was built.

SYSTEM / END-TO-END FLOW

From a physical zone to a digital event

The ceiling transmitter emits a coded infrared beacon over a predefined area. When the receiver on the shopping cart enters that area, it detects the beacon, timestamps the event and sends it over Wi-Fi. The backend can then associate the event with a zone and support notifications and movement-pattern analysis.

01Transmitter defines the infrared zone
02Receiver detects entry and sends an event
03Backend supports notification and analysis workflows
NODE 01 / TRANSMITTER

The invisible boundary

Mounted on the ceiling, the transmitter floods a cone-shaped zone with a coded 940nm infrared beacon.

I designed the circuit and driver stage on perfboard, wrote the embedded beacon-control firmware and developed the custom 3D-printed enclosure.

NODE 02 / RECEIVER

The mobile sensing node

Attached to the shopping cart, the receiver detects the infrared beacon when it crosses into a tracked zone, timestamps the event and sends it over Wi-Fi.

I designed the sensing and power circuit, battery supply, embedded firmware and uplink, plus the hooked enclosure used to mount the node to the cart.
