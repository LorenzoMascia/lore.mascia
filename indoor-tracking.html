Indoor
Tracking System

An end-to-end prototype for detecting when a retail cart enters a predefined store zone, connecting physical infrared nodes to backend events, notifications and movement-pattern analysis.

Mar–Oct 2024 ESP32 infrared localization embedded firmware FDM enclosures
01 / SYSTEM

From a physical zone to a digital event

The project combines two custom hardware nodes with a software pipeline. The prototype was designed as one complete system rather than a collection of disconnected components.

A ceiling-mounted transmitter emits a coded infrared beacon over a predefined area. The receiver attached to the shopping cart detects the beacon when it crosses into that area, timestamps the event and sends it over Wi-Fi.

The backend can associate the event with a store zone and use it as an input for personalized notifications and movement-pattern clustering.

01Transmitter defines the infrared zone
02Receiver detects entry and timestamps the event
03Wi-Fi carries the event to the backend service
04Software supports notifications and analysis
02 / HARDWARE

Two nodes, designed as one system

Both prototypes were developed from circuit and enclosure sketches through working perfboard implementations and custom 3D-printed housings.

NODE 01 / IR TRANSMITTER

The invisible boundary

Mounted on the ceiling, the transmitter floods a cone-shaped area with a coded 940nm infrared beacon. This creates the invisible zone boundary used by the rest of the system.

I designed the circuit and driver stage on perfboard, wrote the embedded beacon-control firmware and developed the enclosure around the working prototype.

mcuESP32-WROOM-32
driver2N2222 NPN + current-limiting resistor
emitter940nm infrared LED
power5V via screw terminal
enclosureCustom FDM 3D print
NODE 02 / IR RECEIVER

The mobile sensing node

Attached to the shopping cart, the receiver detects the transmitter's beacon, timestamps the zone-entry event and sends it over Wi-Fi to the backend.

I designed the sensing and power circuit, battery supply, embedded firmware and uplink, together with the hooked enclosure used to mount the node to the cart.
